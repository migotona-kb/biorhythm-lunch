# Biorhythm Lunch 🍽️

A mobile app that recommends lunch based on your daily biorhythm.

## Tech Stack
- React Native
- Expo
- TypeScript
- Expo Router
- AsyncStorage

## Features
- Birth date input
- Daily biorhythm calculation
  - Physical
  - Emotional
  - Intellectual
- Lunch recommendation based on biorhythm
- Random food recommendation
- Birth date saved locally
- Android APK support

## Planned Features
- Biorhythm chart
- Korean / Japanese localization
- Region-specific food recommendations
- Nearby restaurant search using GPS
