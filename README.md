# Biorhythm Lunch 🍽️

A mobile app that recommends lunch based on your daily biorhythm.

## Tech Stack
- React Native
- Expo
- TypeScript
- Expo Router
- AsyncStorage
- React Native Gifted Charts

## Features
- Birth date input
- Daily biorhythm calculation
  - Physical (23-day cycle)
  - Emotional (28-day cycle)
  - Intellectual (33-day cycle)
- Biorhythm chart
  - Physical, Emotional, and Intellectual cycles
  - 15-day view (7 days before and after today)
  - Today's biorhythm highlighted on the chart
- Lunch recommendation based on physical biorhythm
- Random food recommendation
- Birth date saved locally
- Android APK support
- Custom app icon and splash screen
